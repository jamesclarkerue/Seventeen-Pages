# Seventeen Pages Frontend

Next.js frontend for the AI-powered manuscript editing application.

## Setup

1. Install dependencies:
```bash
npm install
```

## Running the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Building for Production

```bash
npm run build
npm start
```

## Features

- **Four Editing Modes**: Choose from Manuscript Critique, Line Edit, Copyedit, or Proofread
- **Real-time AI Feedback**: Get instant professional feedback powered by GPT-4
- **Clean, Intuitive UI**: Easy-to-use interface designed for authors
- **Responsive Design**: Works on desktop and mobile devices

## Requirements

- Node.js 18 or higher
- Backend API running on `http://localhost:8000`
